競艇チャンネル管理 Ver23.42 更新手順

1. PR #22を先にmainへ反映。PR #23のbaseと差分を確認してから、承認者がPR #23をmainへMerge
2. 新タグを含む月を旧関数で確定すると、新タグの件数・目標を後から確定済み履歴へ補えません。リリース前に次回Cronまでの時間とDeploy承認を確認
3. 別途本番Deployの承認を得た後、最初の対象月確定より前に、マージ済みmainの finalize-monthly-achievements だけをCLI/APIで再Deploy
   共有 _shared/youtube.ts を含む正規フォルダ構成で、既存 verify_jwt=false と認証方式を維持。配置後にソースと設定を再取得して照合
4. GitHub Pagesへの反映後、PCを再読み込みし、iPhone PWAを完全終了して再起動
SQL実行、RLS・Cron・Storage・Secret変更、sync-youtube-video再Deploy、過去snapshotの手動実行・再確定は不要です。
既存baseline SQLを無条件に再実行しないでください。
本番には前回の複数画像テーブル/RPCが存在することを読み取り確認済みです。
別の未導入環境を構築する場合はdocs/ARCHITECTURE.mdとdocs/multi-idea-images.mdを参照してください。

確認ポイント
・動画管理は「カード / 超簡素」の2種類だけで、選択が端末内に保存される。旧一覧保存値はカードへ戻る
・削除の失敗・通信停止でもボタンが戻る。結果未確認の場合は再送せず、再読み込みして状態を確認する
・モーダルを開き直すと先頭から表示され、閉じると背景スクロールが戻る
・動画詳細の前後移動は現在のフィルタと並び順を使い、先頭/末尾では止まる
・今月の投稿ペースと今日を含む残り日数あたり必要本数が表示される
・実績は前月からの増減率を表示し、保存済み履歴と当月を比較した過去最高を表示
・3種類の状態フィルタ・投稿日順・一覧内ステータス変更・詳細からの編集/削除は従来どおり
・ホーム「今月の数字」の下に「ぐっさん YouTube 週間投稿スケジュール」が表示
・週間予定はJSTの今日が大きなhero、残り6曜日がPC 6列／スマホ・タブレット3列×2段で表示
・週間予定に旧「基本ルールを見る」が表示されない
・Dashboardの月を切り替えると、投稿日月でまとめた現在のYouTube統計・タグ件数が表示される
・過去月を選択中に再描画・YouTube更新されても選択月が維持される
・実績の過去月は確定snapshotのままで、DashboardのLIVE値とは連動しない
・ログアウト後の通信完了で旧データや購読が復活しない
・下ナビが「ホーム / 動画 / 企画 / 実績」の4個横一列
・動画タグは指定順の現役10種類から複数選択でき、旧「ネット競艇」と未知の歴史タグは編集保存時に維持
・動画タイトル検索、タグ欄の開閉、タグ未設定、検索結果件数が連動し、Tabでフォーカスしたタグが下部ナビの裏に隠れない
・動画一覧はYouTube公開日時（未取得時は入力した投稿日）の新しい順
・編集/タグ/状態変更だけでは動画の並び順が動かない
・通知が相手側に届き、通知画面を開くと全部既読
・企画内アイデアでは通知を作らない
・企画ボード表示が統一
・企画内アイデアの実行済みが黄色
・iPhone入力欄をタップしても自動ズームしない
・登録動画/企画ストックのアイコンが見やすい
・ホームと実績ページに今月のタグ別投稿本数が表示
・ホーム「今月の数字」のYouTube更新が動画画面の一括更新と同じ動作
・実績ページの6指標が「登録者 / 最高再生 / 投稿 / 再生 / 平均再生 / 高評価」の順
・主要6指標と現役10タグの月間目標を設定でき、旧tag_online目標はDB上で維持
・実績の月選択が報酬確認と同じプルダウン方式
・過去月は閲覧専用で、目標編集ボタンが表示されない
・2026年7月は投稿/タグ本数だけ復元し、復元不能値は「履歴データなし」
・2026年8月以降は月替わり後も確定snapshot値と当時目標が変わらない
・実績の年月見出しがスマートフォンでも不自然に折り返されない
・ホームに大きな「今月の目標 / 今月の実績」セクションが表示されない
・ホームに「最近投稿した動画」が表示されない
・黄色バーが当月実績 ÷ 当月目標の達成率を表示し、幅は100%上限
・実績のタグ別投稿本数は、選択月に目標を設定したタグだけ表示
・目標設定・変更では通知を作らない
・「簡単な成績分析」が表示されない
・切り抜き／レース映像タグ付きは0円、競艇ニュース・競艇クイズ・競艇値段は100円、その他はShorts 100円・横動画 1,000円
・報酬確認では100円対象をShorts欄へ1本につき一度だけ合算
・企画内アイデアの追加・編集・ステータス変更が同じ列の親企画順に反映され、表示の追加日は変わらない
・ユーザー向け表示は「投稿待ち」で、既存DBの内部値「編集待ち」は維持
・PCではモーダルが背景クリックで閉じず、Escapeまたは×で閉じる
・YouTube情報はアプリ起動中に最大おおむね1時間間隔で自動同期
